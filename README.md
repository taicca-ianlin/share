# SharePages

用 GitHub Pages 分享靜態 HTML。

- GitHub repo：https://github.com/taicca-ianlin/share（**公開**）
- 網址格式：`https://taicca-ianlin.github.io/share/<網址名稱>/`
- 發布：`bash /d/SharePages/publish.sh <HTML檔或資料夾> <網址名稱>`
- 下架：刪掉 `D:\SharePages\<網址名稱>\` 資料夾，再 commit＋push

🔴 repo 是公開的：放上去的網頁和原始檔，全世界都看得到。機密、公務未公開內容不要放。
